## 2. Phase 1 scope

**Phase 1 builds:** ECS, simulation clock, renderer, debug HUD. Per the directive, Phase 1 is the shared engine core, nothing else.

**Phase 1 deliverables:**

1. A shared engine package (`/engine`) with no imports from individual applications.
2. An ECS (`/ecs`) with entity IDs and typed-array SoA components, running the 100-agent deterministic sim.
3. A shared simulation clock (`/clock`): fixed 60 Hz simulation with interpolated rendering, one shared clock for CPU and GPU.
4. A shared renderer (`/render`): pinned Three.js version, tested WebGL2 fallback, WebGPU probe reported as measured.
5. A debug HUD with profiling (`/debug`): frame time, tick rate, entity count, draw calls, triangles, memory, per device.
6. A city profile stub (`/profiles/city`): the HERMES CITY district as the Phase 1 demo ground.
7. A shared test harness (`/tests`): dependency scan for the no-imports rule, determinism checks, performance budgets.
8. Engine documentation (`/docs`): architecture diagrams, configuration schemas, benchmark results, deployment instructions for GitHub Pages, integration stubs documented as not yet built.
9. A Phase 1 demo page (local only unless NEURO separately approves a Pages deploy): the HERMES CITY district rendered by the shared engine, with the 100-agent sim running on the ECS, labeled as a demo and as pre-launch.

**Phase 1 does not deliver:** construction runtime, persistence, streaming, GPU compute, physics, audio, asset pipeline, the agent-operated city pipeline, versioned integration interfaces, the ROM RIOT profile, production deployment, payment enforcement, an AEGIS runtime, or real 3D geometry. Each of those is assigned to a later phase in section 4. Phase 1 also does not merge, deploy, publish, or spend anything.
